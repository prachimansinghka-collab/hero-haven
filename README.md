# Hero Haven

Create a modern and stylish e-commerce website for collectible action figures featuring popular anime heroes and superhero-inspired characters. The homepage should have a dark futuristic theme with neon blue and red lighting, animated glowing effects, and a premium collector vibe. Add a large hero banner showing dynamic action figures in powerful poses inside glass display cases. Include sections for “Trending Figures,” “New Arrivals,” “Limited Editions,” and “Best Sellers.” The website should feature realistic 3D-style action figures, rotating product cards, smooth hover animations, and a clean navigation bar with categories like Anime, Superheroes, Manga, Movies, and Accessories. Add a shopping cart icon, wishlist button, customer reviews, and a countdown timer for special offers. The design should feel cinematic, energetic, and exciting for collectors and kids, with high-quality visuals, LED shelf backgrounds, and modern fonts.
